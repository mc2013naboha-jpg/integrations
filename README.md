## Структура

```text
.
├── README.md
├── Страница — Интеграции/
│   ├── index.html
│   └── assets/
│       ├── images/
│       ├── fonts/
│       └── brand-source/
├── Страница — Тарифы/
│   ├── index.html
│   └── assets/
│       ├── images/
│       └── fonts/
└── Страница — ИИ-инструменты/
    ├── index.html
    └── assets/
        └── images/
```

Стили и сценарии сохранены внутри соответствующих `index.html`. Ресурсы страниц не зависят от соседних папок: страницу можно передавать разработчику целиком одной папкой. Навигация между тремя страницами использует относительные ссылки.

## Локальный запуск

```bash
git clone https://github.com/mc2013naboha-jpg/integrations.git
cd integrations
python -m http.server 8000
```

После запуска откройте:

- `http://localhost:8000/Страница%20—%20Интеграции/`
- `http://localhost:8000/Страница%20—%20Тарифы/`
- `http://localhost:8000/Страница%20—%20ИИ-инструменты/`

## Совместимость со старыми адресами

До перестройки страницы публиковались по адресам:

- `/integrations/`
- `/integrations/tariffs.html`
- `/integrations/workhere-ai/`

Новая структура намеренно оставляет в корне только `README.md` и три папки страниц. Поэтому сохранить старые адреса статическими файлами-редиректами без нарушения этого требования нельзя. После публикации старые адреса перестанут открывать соответствующие страницы; внешние ссылки нужно заменить на новые адреса из таблицы выше.

Если обратная совместимость важнее строгой структуры корня, можно отдельным изменением вернуть в корень `index.html` и `tariffs.html` с HTML-редиректами, а также папку `workhere-ai/` с редиректом.

## Быстрая проверка перед передачей

- На странице «Интеграции» нажмите несколько планет и убедитесь, что меняются описание и логотипы.
- На странице «Тарифы» раскройте каждый пункт FAQ и проверьте переходы к форме демо.
- На странице «ИИ-инструменты» нажмите на кота в первом экране и проверьте анимацию.
- Перейдите между всеми тремя страницами через верхнюю навигацию.
- Проверьте широкую и мобильную ширину окна; в Network не должно быть ответов `404` для локальных изображений и шрифтов.

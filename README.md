# WorkHere — страницы сайта

Репозиторий содержит три автономные HTML-страницы презентационного сайта WorkHere и все локальные ресурсы, необходимые для их отображения: изображения, логотипы и шрифты. Страницы подготовлены для передачи в основной проект или дальнейшей доработки разработчиками.

## Страницы

| Страница | Назначение | HTML-файл | Ресурсы |
| --- | --- | --- | --- |
| Интеграции | Интерактивная страница с категориями интеграций WorkHere, планетами и карточками сервисов. | [`index.html`](https://github.com/mc2013naboha-jpg/integrations/blob/main/index.html) | [`Интеграции/`](./Интеграции/), [`Шрифты/`](./Шрифты/) |
| Тарифы | Страница с тарифными планами, возможностями и FAQ. | [`tariffs.html`](https://github.com/mc2013naboha-jpg/integrations/blob/main/tariffs.html) | [`Тарифы/`](./Тарифы/), [`Шрифты/`](./Шрифты/) |
| ИИ-инструменты | Отдельная страница с возможностями ИИ-инструментов WorkHere. | [`workhere-ai/index.html`](https://github.com/mc2013naboha-jpg/integrations/blob/main/workhere-ai/index.html) | [`workhere-ai/`](./workhere-ai/), [`workhere-ai/assets/`](./workhere-ai/assets/) |

> Страницы **«Интеграции»** и **«Тарифы»** расположены в корне репозитория. Страница **«ИИ-инструменты»** находится в отдельной папке [`workhere-ai/`](./workhere-ai/).

## Структура репозитория

```text
.
├── index.html                 # Страница «Интеграции»
├── tariffs.html               # Страница «Тарифы»
├── Интеграции/                # Иллюстрации, планеты и логотипы интеграций
│   ├── Планеты/
│   ├── Мессенджеры/
│   ├── Календари/
│   ├── Почты/
│   ├── Телефония/
│   └── CRM и ATS/
├── Тарифы/                    # 3D-иллюстрации и изображения для страницы тарифов
├── workhere-ai/               # Страница «ИИ-инструменты» и её изображения
│   ├── index.html
│   └── assets/
├── Логотипы/                  # Исходные брендовые логотипы
└── Шрифты/                    # Локальные файлы семейства Exo 2
```

## Для разработчиков

### Где находится исходный код

- **Интеграции:** [`index.html`](./index.html).
- **Тарифы:** [`tariffs.html`](./tariffs.html).
- **ИИ-инструменты:** [`workhere-ai/index.html`](./workhere-ai/index.html).

Стили и сценарии каждой страницы находятся в соответствующем HTML-файле. Изображения подключаются относительными путями из указанных выше папок.

### Как открыть локально

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/mc2013naboha-jpg/integrations.git
   cd integrations
   ```

2. Запустите локальный веб-сервер из корня проекта, например:

   ```bash
   python -m http.server 8000
   ```

3. Откройте нужную страницу в браузере:

   - `http://localhost:8000/index.html` — Интеграции;
   - `http://localhost:8000/tariffs.html` — Тарифы;
   - `http://localhost:8000/workhere-ai/index.html` — ИИ-инструменты.

Также страницы можно открыть через расширение Live Server в редакторе кода.

### Что важно при переносе в основной проект

- Сохраняйте относительную структуру папок и имена файлов: HTML-страницы ссылаются на ресурсы относительными путями.
- Вместе с `index.html` переносите папки `Интеграции/` и `Шрифты/`; вместе с `tariffs.html` — `Тарифы/` и `Шрифты/`.
- Для страницы ИИ переносите всю папку `workhere-ai/` целиком, включая `assets/`.
- Если структура основного проекта отличается, обновляйте ссылки на изображения и шрифты осознанно во всех затронутых местах.
- Имена файлов и папок содержат кириллицу и пробелы; при переносе важно сохранить регистр и написание путей.

### Проверка после переноса

- Откройте каждую страницу на широком экране и в мобильной ширине.
- В инструментах разработчика убедитесь, что в Network нет запросов с ошибкой `404` для изображений и шрифтов.
- Проверьте интерактивные элементы: планеты и карточки интеграций на странице «Интеграции», раскрывающиеся элементы на странице «Тарифы» и содержимое страницы «ИИ-инструменты».
